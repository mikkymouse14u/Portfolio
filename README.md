# Michael Tobi — Portfolio

A React + TypeScript + Vite + Tailwind CSS portfolio site.

## Run it locally

```bash
npm install
npm run dev
```

Then open the local URL VS Code / the terminal shows you (usually http://localhost:5173).

## Build for production

```bash
npm run build
```

This outputs a `dist/` folder ready to deploy anywhere static.

## Where to edit things

- `src/components/Hero.tsx` — name, tagline, headline
- `src/components/Projects.tsx` — the `projects` array at the top: add/edit project cards here
- `src/components/Skills.tsx` — the `groups` array: your skills by category
- `src/components/About.tsx` — bio text
- `src/components/Contact.tsx` and `src/components/Footer.tsx` — email, GitHub, social links
